# AI211 – Machine Learning Labs (IIT Ropar)

This repository contains my complete lab work for the **AI211: Machine Learning** course at **IIT Ropar**.

All lab assignments are implemented **from scratch** using Python and are maintained in a structured and reproducible manner. The goal of this repository is to provide an **end-to-end view** of the concepts covered in the course, including dataset generation, model implementation, experiments, visualizations, and written observations.

---

## 📂 Repository Structure

Each lab is organized into its own folder and typically contains:

- 📓 Jupyter Notebook (`.ipynb`)  
  - Complete working code
  - Step-by-step implementation
  - Plots and experimental results  

- 📄 Report / Observations (`.pdf` or `.tex`)  
  - Clear explanations of results
  - Observations written from a learning perspective
  - Interpretation of plots and experiments  

- 📊 Figures / Outputs  
  - Graphs and visualizations generated during experiments  

---

## 🧠 Topics Covered

Some of the key Machine Learning concepts covered across the labs include:

- PAC Learning and Threshold Hypotheses  
- Empirical Risk Minimization (ERM)  
- Bias–Variance Tradeoff  
- Polynomial Regression  
- Gradient Descent and Analytical Solutions  
- Regularization (Ridge and Lasso)  
- Sample Complexity and VC Dimension  
- Realizable vs Agnostic Learning  
- Effect of Noise on Learning  
- Data Visualization and Exploratory Analysis  
- Class Imbalance and Dataset Distribution  
- Gradient Descent Variants (BGD, SGD, Mini-batch)  
- Learning Rate Tuning and Its Effects  
- Training vs Validation Loss Analysis  
- Image Preprocessing Techniques  
- Edge Detection using Canny Algorithm  
- Convolutional Neural Networks (CNN)  
- Batch Normalization and Regularization  
- Pooling Techniques (Max Pooling, Global Average Pooling)  
- Dropout and Overfitting Prevention  
- Optimizers (SGD, RMSprop, Adam, Adagrad)  
- Hyperparameter Tuning (Learning Rate, Depth, Dropout)  
- Model Architecture Design and Evaluation  
- Recurrent Neural Networks (RNN)  
- Vanishing and Exploding Gradient Problems  
- Effect of Hidden Layer Size in RNN  
- Effect of Sequence Length in RNN  
- Model Stability and Convergence Behavior  
- Training Dynamics and Loss Analysis
